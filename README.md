# みんなで ○×クイズ

Svelte 5 + TypeScript のグループ参加型クイズアプリです。フロントエンドは Vite、公開先の API は Cloudflare Workers、永続化は D1（SQLite）を使用します。ローカル開発は SQLite ファイルに保存します。

## 使い方

1. 司会者ページでパスワードを入力し、問題数（1〜30問）を選んでイベントを作成します。
2. 開始前に各問の正解（○・×）を選択して保存します。全問の正解が保存されるまで開始できません。
3. 「参加用QRコード」を画面に表示するか、PNGで保存して配布します。
4. 各グループの代表者1名が読み取り、グループ名を登録します。
5. 司会者が「第1問を開始する」を押し、問題を会場で出題します。
6. アプリには問題番号だけを表示します。問題文の入力・保存は不要です。
7. グループで相談して○または×を選択します。「決定」までは選び直せます。「決定」後はサーバーでも変更を拒否します。
8. 司会者が回答を締め切り、札を上げてもらい、次の問題を開始します。
9. 最終問の回答を締め切った後、「クイズを終了する」を押します。

問題数と正解はイベントごとに設定します。問題の内容や分野は固定せず、問題文をアプリに登録する必要もありません。終了後、司会者画面にチーム別の正解数を多い順で表示します。進行中は現在の問題について○、×、未回答を表示します。既存の10問イベントには従来の正解「×、×、×、×、○、○、×、×、○、×」を引き継ぎます。

## ローカル開発

Node.js 22 以上を使用します。

```sh
npm ci
npm run dev
```

標準ポートは 5173。使用中の場合は `npm run dev -- --port 5186` などを指定します。

データは `.local/quiz.sqlite` に保存されます。公開先のデータとは別です。開発用URLのQRコードは他の端末では使えません。

```sh
npm run check
npm test
npm run build
```

## 認証とデータ保護

- 司会者はパスワードを入力してイベント一覧・集計・進行操作を利用します。パスワードはサーバー側の `HOST_PASSWORD` で照合し、ブラウザーにはタブのセッション中だけ保存します。別端末・別ブラウザーからも同じパスワードで入れます。
- 参加者APIにはグループ一覧・他グループの回答・集計値を含めません。
- 参加者はイベント別の HttpOnly Cookie で識別し、サーバーにはトークンの SHA-256 ハッシュを保存します。Cookieは14日間有効です。
- 確定回答はグループと問題番号の複合主キーで一意に保存します。異なる回答への変更APIはありません。
- 回答締め切りと問題番号を INSERT 文内で確認し、画面が古いままの送信も拒否します。
- 同じグループ名の重複登録は拒否します。回答者はイベント終了まで同じ端末・同じブラウザーを使用してください。Cookie削除や別端末への引き継ぎは対応していません。
- APIはキャッシュせず、状態は約2秒ごとに更新します。接続失敗時にはエラーを表示します。

## 公開

`.openai/hosting.json` に Sites のプロジェクトIDと論理D1バインディング `DB` を保存しています。公開ビルドは `dist/server/index.js` と `dist/client/` を生成します。Workerに静的ファイルも埋め込むため、追加のアセットバインディングは不要です。

公開アクセスに設定し、回答者はログインなし、司会者はパスワードで利用できます。`HOST_PASSWORD` はSitesのシークレットとして設定します。

`1234` は4桁で推測されやすいため、URLを知る第三者に試される可能性があります。運用時は長いパスワードへの変更を推奨します。

DBスキーマは `db/schema.ts`、マイグレーションは `drizzle/` にあります。適用済みのマイグレーションは変更せず、スキーマ変更時は `npm run db:generate` で追加します。

## 確認した動作

APIテストでは司会者パスワード、別端末からのイベント一覧・進行、問題文なしでの開始、司会者以外への集計拒否、回答データの非公開、重複名、参加者Cookieの継続、不正Cookie、同時確定、回答の変更不可、再送の冪等性、締め切り、10問の進行を検証しています。
