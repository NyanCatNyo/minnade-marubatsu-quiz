# みんなで ○×クイズ

Svelte 5 + TypeScript のグループ参加型クイズアプリです。フロントエンドは Vite、公開先の API は Cloudflare Workers、永続化は D1（SQLite）を使用します。ローカル開発は SQLite ファイルに保存します。

## 使い方

1. `/host` で司会者がイベントを作成します。ChatGPTへのログインは不要です。
2. 「参加用QRコード」を画面に表示するか、PNGで保存して配布します。
3. 各グループの代表者1名が読み取り、グループ名を登録します。
4. 司会者が「第1問を開始する」を押し、問題を会場で出題します。
5. アプリには「第1問」〜「第10問」の番号だけを表示します。問題文の入力・保存は不要です。
6. グループで相談して○または×を選択します。「決定」までは選び直せます。「決定」後はサーバーでも変更を拒否します。
7. 司会者が回答を締め切り、札を上げてもらい、次の問題を開始します。
8. 第10問の回答を締め切った後、「クイズを終了する」を押します。

第1〜2問は狂言、第3〜4問は伝統工芸、第5〜10問は雑学・学校という全10問の構成です。問題文をアプリに登録する必要はありません。正解は「×、×、×、×、○、○、×、×、○、×」です。終了後、司会者画面にチーム別の正解数を多い順で表示します。進行中は現在の問題について○、×、未回答を表示します。

## ローカル開発

Node.js 22 以上を使用します。

```sh
npm ci
npm run dev
```

標準ポートは 5173。使用中の場合は `npm run dev -- --port 5186` などを指定します。

データは `.local/quiz.sqlite` に保存されます。公開先のデータとは別です。開発用URLのQRコードは他の端末では使えません。

```sh
npm run check
npm test
npm run build
```

## 認証とデータ保護

- 回答者・司会者ともChatGPTへのログインは不要です。
- イベント作成時に推測困難な司会者用トークンを発行し、HttpOnly Cookieとして1年間保存します。トークンのハッシュと一致する場合だけ、サーバーが集計・進行操作を許可します。
- 参加者APIにはグループ一覧・他グループの回答・集計値を含めません。
- 参加者はイベント別の HttpOnly Cookie で識別し、サーバーにはトークンの SHA-256 ハッシュを保存します。Cookieは14日間有効です。
- 確定回答はグループと問題番号の複合主キーで一意に保存します。異なる回答への変更APIはありません。
- 回答締め切りと問題番号を INSERT 文内で確認し、画面が古いままの送信も拒否します。
- 同じグループ名の重複登録は拒否します。回答者と司会者はそれぞれ、イベント終了まで同じ端末・同じブラウザーを使用してください。Cookie削除や別端末への引き継ぎは対応していません。
- APIはキャッシュせず、状態は約2秒ごとに更新します。接続失敗時にはエラーを表示します。

## 公開

`.openai/hosting.json` に Sites のプロジェクトIDと論理D1バインディング `DB` を保存しています。公開ビルドは `dist/server/index.js` と `dist/client/` を生成します。Workerに静的ファイルも埋め込むため、追加のアセットバインディングは不要です。

公開アクセスに設定し、回答者と司会者のどちらもログインなしで利用できます。集計・進行操作はイベントを作成したブラウザだけに許可されます。

Sites 以外へ移行する場合、信頼できる認証基盤で司会者を認証するようにサーバーを変更してください。外部から自由に送信できるHTTPヘッダーをそのまま認証情報として扱ってはいけません。

DBスキーマは `db/schema.ts`、マイグレーションは `drizzle/` にあります。適用済みのマイグレーションは変更せず、スキーマ変更時は `npm run db:generate` で追加します。

## 確認した動作

APIテストでは問題文なしでの開始、司会者以外への集計拒否、回答データの非公開、重複名、Cookieの継続、不正Cookie、同時確定、回答の変更不可、再送の冪等性、締め切り、10問の進行、イベントをまたぐアクセス拒否を検証しています。画面ではイベント作成・参加・回答変更・確定を確認しています。
